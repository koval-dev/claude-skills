# Anti-Patterns and Corrections

## Decorative section numbering

**Symptom:** Unrelated sections receive `01`, `02`, `03` markers to look editorial, or each section starts another numbered list.

**Correct by:** Apply the meaning test and numbered-group limit in `SKILL.md`. Replace decorative markers with clear headings, alignment, whitespace, or rules. Keep numbers that express real order or factual content.

## Card grid reflex

**Symptom:** Every benefit, statistic, quote, or link becomes a rounded card.

**Correct by:** Use typography, rules, shared backgrounds, or column spans. Reserve cards for discrete objects whose grouping or interaction benefits from a boundary.

## Cosmetic redesign

**Symptom:** A requested full redesign changes only padding, colour, radius, and heading size.

**Correct by:** Revisit section relationships, media placement, text measure, and grid proportions. A requested polish pass can remain narrower.

## Repeated section template

**Symptom:** Every section repeats an eyebrow, heading, paragraph, and three columns.

**Correct by:** Give sections roles in the narrative, combine minor sections, and use different proportions where their content benefits.

## Arbitrary-value drift

**Symptom:** Custom Tailwind values and nearly duplicated dimensions replace the existing system.

**Correct by:** Map styles back to project tokens. Add a reusable token only for a recurring gap.

## Meaningless asymmetry or effects

**Symptom:** Random offsets, gradients, shadows, or overlays compensate for weak composition.

**Correct by:** Strengthen scale, alignment, contrast, and whitespace. Tie remaining offsets to grid or media anchors.

## Weak mobile result

**Symptom:** Desktop columns become an undifferentiated vertical list.

**Correct by:** Restore emphasis through proportions, compact captions, selective dividers, and varied density while preserving logical reading order.

## Hero without purpose

**Symptom:** Oversized text, vague copy, and generic media consume the opening viewport.

**Correct by:** Use a deliberate relationship between headline, context, media, and next action to communicate the page's value.
