# Choosing a Design Direction

Choose one direction internally based on the content and brand. These are starting lenses, not templates.

## Swiss editorial

Use when information, credibility, typography, and structure matter most.

- strong baseline and column alignment;
- asymmetric text and media placement;
- restrained colour fields;
- visible rules, labels, numbering, and metadata;
- sharp scale contrast;
- generous but controlled whitespace.

## Institutional modernism

Use for education, public service, cultural, research, and civic content.

- clear hierarchy and trustworthy tone;
- broad content grid with narrow supporting columns;
- purposeful brand-colour blocks;
- factual captions and wayfinding;
- strong accessibility and predictable interaction;
- enough visual character to avoid a bureaucratic template.

## Image-led editorial

Use when strong photography or video exists.

- make media part of the grid rather than a rectangular decoration;
- pair large imagery with compact editorial text;
- use crops, captions, sequencing, and scale changes intentionally;
- avoid overlays that reduce readability;
- let some sections become quieter after strong media moments.

## Typographic campaign

Use for concise promotional or event pages.

- treat headlines, dates, numbers, and calls to action as graphic elements;
- use dramatic scale differences with disciplined alignment;
- repeat one motif, such as rules, labels, blocks, or offset columns;
- keep supporting copy short and readable;
- avoid turning the page into a collection of promotional cards.

## Selection test

Choose the direction that best answers all four questions:

1. Does it fit the content and audience?
2. Can the existing design system express it?
3. Does it create a recognizable page silhouette?
4. Can it survive mobile without losing its idea?
