# Grid and Typography Rules

## Grid

- Establish common left and right anchors before styling individual sections.
- Use a 6-, 8-, or 12-column grid when the page benefits from editorial composition.
- Let primary content occupy more columns than supporting content.
- Use empty columns intentionally; do not fill every cell.
- Break the grid rarely and visibly. A break should create emphasis, not repair weak alignment.
- Keep full-bleed backgrounds distinct from full-width readable content.
- Use nested grids only when they preserve the parent anchors.
- Avoid too many unrelated container widths.

## Section rhythm

- Vary density across the page.
- Follow a dense section with breathing room when the content allows it.
- Use contrast in scale, width, or background to mark meaningful transitions.
- Do not rely on larger vertical padding as the only transition device.
- Repeat one or two compositional motifs so the page feels related from top to bottom.

## Typography

- Prefer 55-75 characters per line for sustained body copy.
- Use narrower measures for introductory or high-emphasis copy.
- Use deliberate line breaks only when they remain sensible across responsive widths.
- Avoid too many heading sizes and weights.
- Let spacing, placement, and measure contribute to hierarchy.
- Keep metadata compact and visibly subordinate.
- Use uppercase sparingly and avoid long uppercase passages.
- Check rag shape, widows, and awkward single-word lines where practical.

## Mobile transformation

- Preserve the dominant message and motif.
- Reorder visual emphasis without changing accessible reading order.
- Remove decorative overlap that causes fragile wrapping.
- Keep key labels close to their content.
- Avoid a long sequence of visually identical stacked blocks.
- Retain alignment through consistent mobile gutters and internal rules.
